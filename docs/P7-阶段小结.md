# P7 阶段小结 — RAG 增强与 AI 运营分析

> 日期：2026-11-26 ｜ 对应 tag：v0.8.0 ｜ 目标：文档可上传、可分块、可持久化检索；运营数据可生成结论

## 一、RAG 管线（替换 P6 的内存 TF-IDF）

```
上传(.md/.txt/.pdf) → 解析文本 → 分块(500 字 / 重叠 80，中文句边界)
  → 向量化(默认离线哈希 2048 维；Ollama bge-m3 可选) 
  → Chroma 持久化(ai/data/rag/chroma) → 检索(向量召回 top12 → 领域词/标题加权 → MMR λ=0.7 → k=4)
```

| 模块 | 文件 | 说明 |
|---|---|---|
| 分块 | `app/agent/rag/chunker.py` | 句末标点切分、超长句硬切、相邻块 80 字重叠、保留换行 |
| 向量 | `app/agent/rag/embeddings.py` | `hash`（默认，零依赖）/ `bge-m3`（Ollama，`AI_EMBEDDING=bge-m3` 启用，失败回退哈希） |
| 索引 | `app/agent/rag/store.py` | Chroma PersistentClient + 文档注册表（含原文，支持重建）；增/删/查/统计 |
| 重排 | `app/agent/rag/retriever.py` | 混合打分（向量 0.6 + 领域词 0.12 + 标题 0.15）+ MMR 去冗余 |

接口变化：

| 接口 | 变化 |
|---|---|
| `POST /knowledge/upload` | 新增：`{filename, contentBase64}`，支持 md/txt/pdf，≤2MB |
| `GET /knowledge/stats` | 新增：provider/dim/documents/chunks/chunkSize/overlap |
| `POST /knowledge/search` | 新增 `useMmr` 开关，返回块序号与分数 |
| `GET /knowledge/documents` | 新增 `chunks` 字段 |

> 用 base64 JSON 而非 multipart，避免引入 `python-multipart` 依赖，离线/CI 均可跑。

## 二、AI 运营分析（预定义口径，不生成 SQL）

`GET /agent/ops/overview`（需管理员 Token 透传）：

- 统计来自 `GET /api/admin/stats/overview`：今日订单/营收、停车场与车位、空闲/占用、待用预约
- 高峰来自 P5 预测模型：未来 12 小时最紧张时刻与空闲位
- 输出结构化数据 + 一段可直接展示的结论（模板拼接，不编造）
- 异常分级：无 Token → 401；非管理员 → 403；后端不可用 → 502；预测失败不影响统计部分

管理端新增「运营分析」页：4 个指标卡（订单/营收/空闲/预测高峰）+ 结论区，支持一键重新生成。

### 联调中发现并修复的 3 个真问题

1. **LLM 改写数据导致幻觉**：「附近哪里有空位」工具已返回 3 个停车场，7B 模型却答「暂无在营停车场」。
   修复：数据类意图（车位/订单/预约/停车中/预测）保持模板输出，只有知识类回答交给模型润色；补回归测试。
2. **关键词抽取把「有」当停车场名**：`(有没有|有|…)` 规则把「附近哪里有空位」清洗成「有」，后端 LIKE 无结果，误报「没有停车场」。
   修复：停用词补全 + 单字关键词视为无效，补 2 条测试。
3. **并发初始化索引互删集合**：管理端同时请求 documents 与 stats，两个线程同时重建 Chroma 集合 → `Collection does not exist` 500。
   修复：单例双检锁 + 索引初始化全局锁；补 6 路并发回归测试。

另修复登录页在 1016px 高度下按钮被裁切的布局问题。

测试总数：AI **74/74**（新增 5 条：数据不被改写、关键词为 None、关键词解析、并发 6 路、LLM 润色知识问答）。
