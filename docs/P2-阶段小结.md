## 三、关键设计（答辩可讲点）

1. **状态机集中管理**：`SpaceStateMachine` 用 `EnumMap` 声明合法流转，业务层不再散落 if-else；非法流转报错信息直接带中文状态名，测试与前端提示一致。
2. **条件更新防并发覆盖**：先读状态做校验，再用 `WHERE status = 原状态` 更新；返回 0 行说明已被他人改动，直接提示刷新——比加锁更轻，P3 预约也会复用。
3. **车位编号唯一性双保险**：`UNIQUE(lot_id, space_no)` 数据库约束 + 批量创建前友好查重（返回具体重复编号）。
4. **容量自动同步**：批量创建后按实际车位数回写 `parking_lot.capacity`，避免容量与车位表不一致。
5. **金额用分存储**：`first_hour_cents` 等字段为整数分，规避浮点误差，P3 计费引擎直接使用。
