# P6 阶段小结 — AI 助手（Agent + RAG）

> 日期：2026-11-26 ｜ 对应 tag：v0.7.0 ｜ 目标：能查真实数据、能引用规则、能流式输出的停车助手

## 一、能力总览

| 能力 | 实现 |
|---|---|
| 规则问答（RAG） | 5 篇内置规则文档 + 管理员可追加，字符向量召回 + 领域词重排，回答带来源 |
| 实时数据查询 | 工具透传用户 Token 调用业务后端：停车场空位、我的预约、我的订单、当前停车 |
| 占用率预测 | 复用 P5 模型，回答「今天下午会满吗」类问题 |
| 流式输出 | SSE：`meta`（意图/工具/来源/建议）→ `delta`（逐段文本）→ `done` |
| 大模型（可选） | Ollama qwen2.5:7b；**未安装/未启动时自动走规则引擎**，功能不降级、测试不依赖 |
| 管理端 | 知识库增删查 + 检索测试（看命中分与片段） |

接口：

```
POST /agent/chat            { message } → { answer, intent, toolCalls, sources, suggestions }
POST /agent/chat/stream     SSE 事件流
GET  /agent/llm/status      Ollama 可用性与模型名
GET  /knowledge/documents   文档列表
POST /knowledge/documents   新增（title ≥2 字，content ≥10 字）
DELETE /knowledge/documents/{id}  仅自定义文档可删
POST /knowledge/search      { query, topK } → 命中片段与分数
```

## 二、实现结构

```
ai/app/agent/
  knowledge.py   文档装载（内置 md + 自定义 json）、TF-IDF 向量索引、关键词重排、增删
  tools.py       后端工具（httpx，透传 Bearer Token）、预测工具
  engine.py      意图识别 → 工具调用 → 模板作答（可选 LLM 润色）、SSE 分片
  llm.py         Ollama 探测（30s 缓存）与生成，失败静默降级
  schema.py      请求/响应模型
ai/app/api/agent.py  对话 + 知识库接口
ai/knowledge/*.md    收费标准 / 预约规则 / 停车流程 FAQ / 预测说明 / 账户安全
```

意图路由（确定性、可测试）：问候、查车位、我的预约、我的订单、停车中、占用率预测、规则问答、未知兜底。

## 三、前端

**用户端（新增 AI 助手页）**
- 玻璃气泡对话、AI 头像、打字机流式渲染、来源标签（文档名 + 匹配度）、工具执行标签（查询停车场/检索知识库…）
- 建议问题 chips 会随回答更新；H5 用 `fetch` 读 SSE，小程序或无流式环境自动降级为普通请求
- 入口：首页右下角 AI 悬浮球 + 个人中心菜单

**管理端（新增「AI 知识库」页）**
- 文档表格（内置只读 / 自定义可删）、新增文档对话框（标题+Markdown 正文）
- 检索测试面板：输入问题即时看命中标题、来源、匹配度与片段
- AI 服务未启动时显示错误卡片与启动命令

## 五、已知限制

1. 本机未启动 Ollama，回答由规则引擎生成；启动 `ollama run qwen2.5:7b` 后自动切换为大模型润色（提示词已限定时长 120 字）。
2. 本机 Docker 未运行，MySQL 未启动，因此「查真实车位 / 我的订单」工具链路只做了**未登录降级**与单元 mock 验证；启停 infra 后可直接联调。
3. 检索为 TF-IDF 字符 n-gram + 关键词重排，未接向量数据库；文档量 <1000 时效果与延迟都优于外部 embedding（且离线可用）。如需 Chroma，替换 `KnowledgeStore` 内部的 vectorizer 即可，接口不变。
4. 对话历史暂未入库，`history` 字段已预留但引擎未使用（多轮指代消解留给 P7）。

## 六、踩坑记录

| 问题 | 原因 | 处理 |
|---|---|---|
| 「停车怎么收费」命中「停车流程」 | 字符向量被高频词「停车」主导 | 增加领域关键词加权（收费/费用/价格…）并保留语义阈值，避免加权误召回 |
| 删除自定义文档后仍命中收费文档 | 仅靠关键词加分把不相关文档拉进结果 | 同时校验基础余弦分，低于 0.03 且总分 <0.2 直接丢弃 |
| 回答里 Markdown 列表挤成一行 | 片段生成时用空格拼接 | 保留换行 + 将 `- ` 转 `• `，移动端可读 |
| 长回答看不到末尾 | `scroll-into-view` 只滚到气泡顶部 | 改为递增 `scroll-top` 直接贴底 |
| 未登录提示文案不准确 | 复用「个人数据」话术 | 按意图区分：查车位提示登录后查实时空位 |
