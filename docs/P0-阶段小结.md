## 三、踩坑与处理

| 问题 | 原因 | 处理 |
|---|---|---|
| uni-app 官方模板拉取失败 | `degit` 走 GitHub，网络不可达 | 改为按 uni-app 官方包版本手工搭建（锁定 `3.0.0-5030420261029002`） |
| pip 安装中途异常退出 | 沙箱对 pip 缓存删除动作的限制触发 SystemExit | 使用 `--no-cache-dir` 安装，绕开缓存清理 |
| admin `vue-tsc -b` 报 TS6310 | 引用项目同时 `composite` 与 `noEmit` 冲突 | 去掉 project references，合并为单一 tsconfig，补 `@types/node` |
| uni-app 构建报 App.vue 无 template/script | `<script setup>` 空块被解析器忽略 | 写入 `onLaunch` 启动钩子 |
| 首次 push 卡住 | HTTPS 走 Git Credential Manager，等待交互式登录 | 本机已有 SSH key 且 GitHub 已授权，改用 SSH 远程地址 |
| Docker 未启动 | Docker Desktop 服务未运行 | 仅做 `docker compose config` 校验；启动 Docker Desktop 后执行 `docker compose up -d` 冒烟 |
