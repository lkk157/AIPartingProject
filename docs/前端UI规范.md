# 前端 UI 规范（依据参考图）

> 参考来源：项目方提供的 5 张移动端效果图（首页 / 预约车位 / 停车缴费 / 停车记录 / 个人中心）
> 适用范围：`app/`（uni-app 用户端，H5 + 微信小程序）为主，`admin/`（Vue3 + Element Plus）沿用同一套色彩与圆角语言
> 设计基准：750rpx 设计稿宽度，移动端优先

---

## 1. 设计基调

- **风格**：明亮蓝色系 + 大圆角白卡 + 轻投影，信息层级靠卡片分组而非分割线堆叠
- **气质**：工具型应用，强调"一眼看懂"：数字大、按钮大、状态色明确
- **禁忌**：不用深色背景（除渐变头部）、不用高饱和描边、不做多层嵌套卡片

## 3. 页面结构规范

### 3.1 首页（index）

```
[渐变头部]
  大标题「智泊停车」+ 副标语「快速找位 · 预约停车 · 无感支付」
  Hero 图（停车场闸机场景插画，圆角 16 卡内嵌）
[数据卡] 三列等分：空闲车位 128 / 今日预约 36 / 实时缴费 24
        数字 28px 700 主色，标签 13px 次级色，列间 1px 分隔线
[功能宫格] 4 列：预约车位(蓝) / 导航入场(绿) / 停车记录(蓝) / 我的优惠券(橙)
          图标为 48px 圆角方块（浅色底 + 主题色图标），文字 13px
[附近停车场] 卡片列表：左侧 P 图标（56px 圆角 12）+ 名称 17px 600
            + 第二行「剩余 42 位」（剩余数值用主色加粗）+ 右侧「距离 0.8km」+ 箭头
底部：tabbar（首页 / 预约 / 订单 / 我的），激活色主蓝
```

### 3.2 预约车位（reservation）

```
导航栏：居中标题「预约车位」+ 返回
[停车场卡] P 图标 + 名称 + 「B2 层 · 西区」+ 右侧箭头（可切换停车场）
[车位选择卡]
  车位网格：每格 52×52，圆角 8，间距 10
  状态：空闲=绿底白字 / 已选=蓝底白字 / 已约=灰底白字(禁用)
  布局模拟真实车位：两侧按排、中间留车道
  选中态：浮出气泡标签显示车位号（如 B2-036，白底蓝边 + 阴影）
  顶部提供图例：空闲 / 已选 / 已约
[时间卡] 行式布局：入场时间（日期时间选择器）/ 停留时长（小时选择）
        右侧配图标，行间 1px 分隔线
[费用卡] 「预计费用」+ 右侧橙色金额 24px 700
底部固定：[确认预约] 胶囊主按钮（含 safe-area 适配）
```

### 3.3 停车缴费（payment）

```
导航栏：居中「停车缴费」
[车牌卡] 「车牌号码」+ 车牌（20px 700，支持 粤A-12345 格式）
        下方出口场景插画（闸机 + 车辆，浅蓝底圆角区）
[费用明细卡] 行式：停车时长 / 停车费用 / 优惠券 / 实付金额
           金额统一右对齐橙色（优惠券为负数 -¥6.00），实付金额加粗 26px
[支付方式卡] 三列：微信支付 / 余额支付 / 月卡支付（图标 + 文字，选中态勾选）
           注：本项目为模拟支付，页面底部注明「模拟支付环境」
底部固定：[立即支付] 胶囊主按钮 + 下方提示「支付完成后自动抬杆离场」
```

### 3.4 停车记录（records）

```
导航栏：居中「停车记录」+ 右侧筛选图标
[统计卡] 三列：本月停车 18 次 / 累计缴费 ¥216.00 / 预约成功率 92%
        顶部小图标（蓝/橙/蓝），数值 24px 700
[记录卡] 标题行：停车场名 + 右侧状态徽章（已完成=浅绿底绿字）
        明细行：入场时间 / 离场时间，右侧费用（已支付用绿色 ¥28.00）
        卡片底部细进度条可选（表示时长占比）
[底部] [导出记录] 胶囊按钮（次级样式：白底主蓝描边或主色填充，与设计稿一致用实心）
```

### 3.5 个人中心（profile）

```
[渐变头部] 左侧头像（72px 圆形白边）+ 昵称 22px 700 + 车牌 15px 半透明白
          + 金色会员徽章（胶囊，金渐变，12px）
[功能宫格卡] 4 列：我的预约 / 优惠券 / 月卡管理 / 车辆管理
[列表卡] 行式：账单明细 / 客服帮助 / 消息通知 / 地址管理
        左侧线性图标（主色）+ 文字 15px + 右侧箭头，行高 52
[底部提示] 「车辆信息已加密保护」浅色小字 + 锁图标
```

### 3.6 AI 智能助手（扩展页，风格延续）

- 对话区背景 `--page-bg`；用户气泡主蓝白字（右对齐，圆角 16/4），AI 气泡白底深灰字（左对齐，圆角 4/16）
- AI 气泡内可嵌"停车场比较卡片"：沿用列表卡样式，含费用/空位/预测拥挤度三行
- 工具调用过程以可折叠的「正在查询…」状态条展示（不暴露内部参数）
- 高危操作（创建预约）以确认卡片形式出现：蓝边卡片 + 「确认预约」按钮，**不自动执行**
- 输入区底部固定：圆角输入框 + 发送按钮，含 safe-area

## 4. 组件规范（uni-app 落地）

| 组件 | 说明 |
|---|---|
| `AppNavBar` | 渐变导航，状态栏高度自适应，标题居中，支持返回/右侧插槽 |
| `StatCard` | 三列统计卡，支持分隔线与自定义单位 |
| `QuickGrid` | 4 列/3 列功能入口，图标为圆角色块 |
| `LotListItem` | 停车场列表行：P 图标 + 名称 + 剩余/距离 + 箭头 |
| `ParkingSpaceGrid` | 车位网格：接收车位数组（编号/状态），抛出 select 事件，含图例与气泡 |
| `SummaryRow` | 左右两栏费用明细行，支持金额色（橙/绿/灰） |
| `StatusBadge` | 状态徽章：success / warning / info / default 四种 |
| `PayMethodPicker` | 支付方式三选一（模拟） |
| `PrimaryButton` | 胶囊主按钮，含禁用态与 loading |
| `EmptyState` | 空列表占位（图标 + 文案 + 可选操作） |

**技术约束**
- 单位统一 `rpx`；颜色、圆角、字号一律走 SCSS 变量（`styles/tokens.scss`），禁止页面内硬编码色值
- 状态色语义固定：绿=空闲/已完成，蓝=选中/主操作，灰=不可用，橙=应付金额/待处理
- 所有底部操作栏需适配 iPhone 安全区 `env(safe-area-inset-bottom)`
- 列表页统一：下拉刷新 + 触底加载 + 骨架屏
- 小程序端注意：不使用 `position: fixed` 与原生组件混排的场景；长列表用 `scroll-view`

## 5. 管理端（admin）对齐规则

- 主色 `#2563EB`，Element Plus 通过 `--el-color-primary` 覆盖
- 卡片圆角 8px、阴影同用户端；表格斑马纹关闭，用 1px 浅分隔线
- 看板图表配色顺序：`#2563EB / #22C55E / #FF8A00 / #8B5CF6 / #94A3B8`
- 金额展示统一橙色，状态标签沿用用户端语义

---

## 6. 验收要点（P4）

1. 与参考图同页面的信息层级一致（卡片分组、数字大小对比、按钮位置）
2. 车位网格三态颜色与图例一致，选中气泡可用
3. 金额颜色语义正确：应付橙、已付绿
4. 全页面 375px 宽度无横向滚动、无文字截断
5. 小程序端实机检查：安全区、滚动、渐变渲染
