# P4 阶段小结 — 管理端与用户端页面

> 日期：2026-11-25 ｜ 对应 tag：v0.5.0 ｜ 阶段目标：双端页面全部对接真实接口，端到端可操作

## 一、完成内容

### 管理端（Vue3 + TS + Element Plus + ECharts）

| 模块 | 内容 |
|---|---|
| 基础设施 | axios 封装（统一解包、401 清 token 跳登录、错误提示）、Pinia 认证 store（localStorage 持久化）、路由守卫（未登录跳转 + 角色校验）、后台布局（侧栏 + 顶栏） |
| 登录页 | 表单校验、登录后回跳原页面、默认账号提示 |
| 运营看板 | 真实统计（停车场/车位/空闲/占用/今日订单/今日营收/待用预约）+ ECharts 环形图 |
| 停车场管理 | 关键词/区域/状态筛选、分页、新建/编辑对话框、删除确认、行点击进详情 |
| 停车场详情 | 车位统计、车位网格（按状态配色）、点击车位按状态机给出可选目标状态、批量创建车位、收费规则增删改（元/分自动换算） |
| 用户管理 | 搜索、角色标签、启用/禁用开关（admin 自身禁止） |
| 订单管理 | 状态筛选 + 订单号/用户搜索、金额与计费时长格式化 |
| 预约管理 | 状态筛选、车位号/用户/时间段展示 |

### 用户端（uni-app H5）

| 模块 | 内容 |
|---|---|
| 请求层 | `uni.request` 封装：Bearer token、统一解包、401 清理登录态并跳登录、Toast 错误提示 |
| 首页 | 登录态展示、在营停车场列表（真实 `/api/lots`）、快捷入口 |
| 停车场详情 | 车位网格（状态配色）、选择空闲车位、整点时段选择（未来 12 小时）、时长 1-4 小时、预约、临停入场（车牌号） |
| 我的预约与订单 | 双 Tab；预约可取消；订单可支付（模拟支付） |
| 登录/注册 | 同一页面切换，注册后自动登录 |

### 后端补充（管理端所需）

- `GET /api/admin/orders`（分页 + 状态 + 订单号/用户名搜索）
- `GET /api/admin/reservations`（分页 + 状态）
- `GET /api/admin/stats/overview`（运营概览）
- 修复：预约时段重叠校验改为只统计「待使用」预约（已完成的历史预约不再阻塞后续时段）

## 四、踩坑记录

| 问题 | 原因 | 处理 |
|---|---|---|
| 管理端订单列表 500 | MyBatis 记录映射列数与 VO 不一致（VO 多 statusText） | 新增 `AdminOrderRow` / `AdminReservationRow` 投影，状态文案在服务层补 |
| 用户端预约提示「该时段已被预约」 | 重叠校验把已完成的预约也算作占用 | SQL 改为 `status = 0`，历史预约不再阻塞 |
| vitest 全量运行偶发漏跑测试文件 | 沙箱写入临时目录 EPERM | 重跑即可；单文件运行正常，非代码问题 |
| `el-page-header` 双重返回文案 | 同时使用默认返回与 content | 移除 content |
