# P4.5 UI 升级 — 玻璃拟态主题 + 车主端功能补全

> 日期：2026-11-25 ｜ 对应 tag：v0.5.1 ｜ 目标：解决「界面普通、车主端功能太少」的问题

## 一、设计语言（玻璃拟态 Glassmorphism）

| 元素 | 方案 |
|---|---|
| 背景 | 三色光晕（蓝 / 紫 / 青）+ 浅色渐变底，`radial-gradient` 叠加，固定不随滚动 |
| 卡片 | `rgba(255,255,255,0.62)` + `backdrop-filter: blur(18px) saturate(150%)` + 1px 白色高光边框 + 柔和投影 |
| 品牌色 | 蓝紫渐变 `#4b7dff → #6a5bff → #8b5cf6`，用于头像、主按钮、停车中卡片、选中态 |
| 层级 | 弱化描边、强化留白与圆角（32rpx / 999rpx 胶囊），次要信息降一级灰度 |
| 兼容 | `backdrop-filter` 在微信小程序 Android 端支持有限，降级为半透明白底（不影响可读性） |

设计令牌集中在 `app/src/styles/tokens.scss`（SCSS 变量 + `glass()` / `pill-chip()` mixin），全局光晕与 `.glass` 类在 `App.vue` 中定义。

## 二、车主端功能补全（不只是换皮）

| 页面 | 新增/升级 |
|---|---|
| 首页 | 问候 + 头像入口；停车场搜索（名称/地址）；区域筛选 chips；**实时「停车中」卡片**（计时到秒、预估费用、去结算）；四宫格快捷入口；停车场卡片显示 **空闲数 / 总车位 / 首小时价**（满位标红）；下拉刷新；分场景空状态 |
| 停车场详情 | 空闲数大徽标 + 总位/占用/预约锁定统计；**收费标准卡**（免费时长/首小时/每小时/24h 封顶，来自真实规则）；车位筛选（空闲/全部/充电桩）；车位状态图例；**底部玻璃操作栏**（已选车位 + 时长 + 时段，一键预约 / 立即停车）；时间选择半屏弹层（未来 12 个整点，最近可约优先） |
| 停车中（新增） | 大号计时器（时:分:秒）+ 预估费用（后端按当前时刻计费）；停车场/车位/车牌/计费规则；离场结算 → 生成账单 → 一键支付；无车时引导去选位 |
| 我的预约与订单 | 玻璃分段控件 + 计数；预约卡展示停车场名、车位、起止时间、取消入口；订单卡展示金额、时长、支付入口、订单号 |
| 个人中心（新增） | 账号信息与角色标签；**我的车辆**（本地保存默认车牌，入场自动带入）；停车中/预约/订单/关于入口；退出登录 |
| 登录/注册 | 品牌区 + 玻璃卡片 + 分段切换，注册后自动登录 |

## 三、后端配套（不是假数据）

| 接口 | 变更 |
|---|---|
| `GET /api/lots` | 列表补充 `freeCount`（批量聚合）与 `priceFromCents`（启用规则首小时价） |
| `GET /api/parking/current` | **新增**：返回进行中停车（停车场名/车位号/车牌/入场时间/已停分钟/按当前时刻预估费用） |
| `GET /api/orders` | 补充 `lotName`、`spaceNo`（批量补全，非 N+1） |
| `GET /api/reservations` | 补充 `lotName` |
| 计费 | 新增 `findEnabledRule`（未配置规则不抛异常，供预估使用） |

## 六、踩坑与限制

| 问题 | 处理 |
|---|---|
| 模板内直接给 `ref` 赋值（`hours = item.value`）存在兼容风险 | 改为 `setHours()` / `setSlot()` 方法调用 |
| `uni.switchTab` 在无 tabBar 时不可用 | 改为 `navigateBack` + `fail` 时 `reLaunch` 兜底 |
| 窄视口（<960px）管理端标题换行 | 加 `nowrap` 与断点收窄侧栏 |
| 小程序 Android 端 `backdrop-filter` 支持不完整 | 降级为半透明白底，功能不受影响 |
| 预估费用与最终结算可能有差异 | 预估按当前时刻计算，最终以离场时刻为准（页面已注明） |
