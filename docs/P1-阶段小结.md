# P1 阶段小结 — 认证与权限（RBAC）

> 日期：2026-11-25 ｜ 对应 tag：v0.2.0 ｜ 阶段目标：用户/角色体系 + JWT 认证 + 接口级权限控制

## 一、完成内容

| 模块 | 内容 |
|---|---|
| 数据库 | Flyway `V1__init_auth.sql`：`user` / `role` / `user_role` 三表 + 索引 + 外键；种子角色 `USER` / `PARKING_ADMIN` / `SYS_ADMIN` |
| 认证 | 注册（用户名/手机号唯一校验）、BCrypt 密码存储、登录签发 JWT（默认 12 小时）、`/api/auth/me`、登出（无状态） |
| 授权 | `@RequireRole` 注解 + `AuthInterceptor` + `UserContext`；未登录 401、无权限 403 |
| 管理端 | 用户分页查询（用户名/昵称/手机号模糊搜索）、启用/禁用；禁止修改自己的状态 |
| 基础设施 | 统一异常处理（400/401/403/500 + 参数校验错误）、统一响应体、管理员账号初始化（`admin/admin123`，可开关） |
| 测试 | **28 个用例全绿**：JWT 4 + 密码 4 + Service 单测 8 + 集成测试 11 + context 1 |

## 二、接口清单

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/api/auth/register` | 公开 | 注册（默认 USER 角色） |
| POST | `/api/auth/login` | 公开 | 登录，返回 token + 用户信息 |
| GET | `/api/auth/me` | 登录 | 当前用户信息与角色 |
| POST | `/api/auth/logout` | 登录 | 无状态登出（客户端丢弃 token） |
| GET | `/api/admin/users` | SYS_ADMIN | 分页 + 关键词搜索 |
| PATCH | `/api/admin/users/{id}/status` | SYS_ADMIN | 启用/禁用用户 |

## 三、关键设计（答辩可讲点）

1. **不引入完整 Spring Security**：用 `HandlerInterceptor` + 注解实现接口级 RBAC，链路短、可调试；BCrypt 复用 `spring-security-crypto`，不自己造密码学。
2. **JWT 内嵌角色**：token 携带 `userId/username/roles`，拦截器一次验签即可完成鉴权，无会话存储；登出为客户端丢弃 token（无状态设计，P1 阶段不引入 Redis 黑名单）。
3. **身份不来自请求参数**：`UserContext` 由拦截器从 token 注入，业务层不接收外部传入的 userId，天然防越权（P6 Agent 工具沿用此机制）。
4. **状态校验在认证之后**：禁用用户即使持有未过期 token 也能登录拦截（登录时校验 status）。
